# Pilotbrief

Inspired by John Miranda’s enterprise AI product marketing and technical-to-commercial translation experience. The fictional pilot shows how discovery gets translated into success criteria, an evidence plan, and a rollout decision.

Open `index.html` directly in a modern browser. No install, account, or backend is required.

Edit or add a criterion, save it, and download a Markdown handoff. The built-in sample is fictional. The workspace lives in memory and resets on reload.


[Open the live demo](https://johnmir94.github.io/pilotbrief/)
